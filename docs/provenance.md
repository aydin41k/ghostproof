# What this release can substantiate

The historical **cached demo** has one finite, reviewed pool, not an open-ended fact generator. Its three subjects were selected by the curator: NPS's account of St Paul's ghost stories; NASA's independent UAP study; and NASA's account of atmospheric sprites. Lore attribution, study-specific scope, lightning association and photographed-jellyfish-instance qualifications stay attached to those claims. The later, separate live local mode is described below; it does not change this historical evidence.

## Later live local mode: separate provenance contract

`local/` discovers public NASA Science WordPress search results on demand, then retrieves a matching ID/type/canonical link through verified `image-article`, `posts` or `topic` endpoints. Gemma chooses short spooky search subjects using recent accepted subjects, not a static claim/property bank. HTML is parsed into normalized complete prose paragraphs; script, navigation, media and known APOD boilerplate are omitted. No images, raw HTML or raw model output are stored or distributed.

Each accepted private round has contract `ghostproof-live-1`, opaque server-generated IDs, the actual local model name, generation time, NASA ID/type/title/canonical URL/retrieval time, numbered paragraphs and SHA-256 of their canonical text (`\n\n` joined UTF-8 paragraphs). This is a canonical prose digest, not a digest of the full HTTP response. Draft quotations must occur verbatim in their numbered paragraph. Short complete sentences are derived and numbered from actual article prose, not a curated sentence/fact bank. The model selects one sentence and an incompatible single-valued property substitution; code applies the substitution and retains the exact original sentence as correction. A second, blinded call to the **same local Gemma model** separately classifies claims without intended labels and checks correction support, scope and distinct factual properties. This automated check is not independent human/agent editorial review or a truth theorem. Both drafting and review can be wrong: inspect the displayed source context yourself.

The choosing projection contains only session/round/claim IDs, topic, three claim texts and game status/score. Source evidence, false identity, correction and automated review appear only after the server grades an answer. Accepted source IDs and cited-passage fingerprints are retained in process memory across hunts; restart can revisit them. No artificial total generation cap exists, but requests have bounded time/attempts and the archive can have no suitable unused result. Failure is visible and recoverable without any cached/fabricated fallback. Runtime records are not packaged, so a ZIP does not reproduce the changing NASA archive or an individual live random draft.

The historical timestamps and approved/deployed-demo evidence below are not claims about this later feature or contest eligibility. No remote submission draft was changed by this work.

The live mutation seam is deliberately conservative: code derives explicit constellation and measured size/distance spans, checks same-kind alternatives, and excludes modal/appearance/containment/conditional/list/example predicates from fake eligibility. A guarded standalone “X is/are/was/were [not] Y” slot allows only its exact predicate-negation toggle, not arbitrary negations or non-exclusive quantified subjects. Ordinary value substitutions cannot mutate negative assertions, ranges, comparative bounds or calendar mentions. Approximate measurements require a widely separated alternative. A generic constellation vocabulary is a value-kind check, not a source/fact bank. Supporting facts retain genuine qualifiers and use distinct sentence IDs. These restrictions were added after live same-model reviews incorrectly accepted non-exclusive and duplicate-property drafts, demonstrating why prompt/reviewer agreement alone is insufficient. At most two live AI search proposals and two drafts share the request deadline; there is no lifetime cap. The automatic parser and review remain fallible and can reject useful articles.

## Context is part of the answer

The accepted correction “Sprites occur far above those cloud tops.” is context-bound. Both visible feedback and the live-status announcement present it immediately after:

> The fabricated claim: “Sprites are positioned near the tops of cumulonimbus clouds.” Correction: Sprites occur far above those cloud tops.

The false-claim card also retains the fake and its exact source context. The correction is never advertised as an independently standalone sentence. The UAP claims concern the specific independent study, not every NASA activity; NPS's local ghost stories are recorded lore, not evidence of a haunting. Absence of information alone is not treated as a contradiction.

## What stays private / what remains limited

No full HTML, transport bodies, credentials, raw responses, rejected text, transcripts, request/fetch ledgers, local paths, source photographs or model weights are shipped. Original preparation code is a historical source-audit snapshot with hashes, not runnable regeneration instructions. Original records remain untouched.

The public static bundle includes answers; a player can inspect or change their own local state. No leaderboard, anti-cheat, production-security or universal-truth claim is made. Automated checks and browser smoke tests are scoped evidence, not an exhaustive accessibility/security audit. Source pages may change after the recorded retrieval times.
